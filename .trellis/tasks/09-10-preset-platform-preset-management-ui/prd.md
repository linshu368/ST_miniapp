# Preset Platform 预设管理 UI

## Goal

实现平台预设/预设库/草稿箱 Tab 与对话页预设抽屉。

## Requirements

- 将平台预设、预设库、预设草稿箱设计为一个“预设管理”功能模块，单页内使用 Tab 切换。
- 平台预设 Tab 支持查看当前默认、保存草稿、发布不可变 release、回滚上一 release、生产二次确认和并发冲突处理。
- 预设库 Tab 支持查看已发布预设的名称、简介、标签、版本、状态、详情和一键应用到当前会话。
- 草稿箱 Tab 只展示当前操作者私有草稿，支持创建、编辑、重命名、保存、覆盖确认、另存和一键用于当前会话。
- 对话测试页点击“预设”选择器时打开右侧抽屉，合并展示已发布预设和我的草稿；抽屉只负责快速选择，完整编辑跳转预设管理页。
- 应用预设只影响当前会话后续请求，不修改历史消息或其他会话。

## Acceptance Criteria

- [ ] 三个 Tab 在同一页面内完成平台默认、预设库和私有草稿管理。
- [ ] 抽屉可从对话页打开，正确显示已发布预设和私有草稿，并应用到当前会话。
- [ ] 发布/回滚有权限、expected revision、防重复、审计结果和生产二次确认。
- [ ] 空名、重名、覆盖、另存、并发冲突行为明确，冲突时保留本地内容。
- [ ] 预设应用不影响历史消息、其他会话或未发布草稿。
- [ ] 根据实现补充 preset-platform features/UI spec。

## Notes

- 依赖 SPA shell 和 backend foundation。
- 该任务 package 暂标 `frontend` 是因为 Trellis 白名单尚无 `preset-platform`。
