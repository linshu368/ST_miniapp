## Requirements

### R1 整体结构

两个独立页：默认图片广场；图片创作（对话式）；无底栏/跨模块入口。广场吸顶「图片广场」+「✦ 去创作」。创作顶栏：历史/收起、新建、标题、‹ 广场。历史默认收起在左侧。

### R2 图片广场

搜索「搜索画面内容」+ 标签组合筛选；局部刷新；空态「查看全部」。标签来自 Admin，「全部」固定。两列纯图瀑布流；点赞+用同款在底部渐变层且拦截进详情；点图片进详情。生产必须游标分页。

### R3 图片详情

竖屏上图下信息。图生图：大图下「查看参考图/查看作品图片」切换。底栏一键复制生成（新建对话、恢复快照、不扣费不调上游）+ 点赞。

### R4 用同款 / 复制生成

每次新建「同款 · 作品名」对话；恢复完整快照；图生图带参考图且可移除；目标模型不支持图生图则不带参考图、不静默换模并提示。

### R5 图片创作

对话流就地生成中/结果/失败；组间「新一轮生成」；输入最多 600 字，Enter 发送 / Shift+Enter 换行 / IME 安全。工具行：+、设置、模型、报价、发送；无变体。+ 仅添加/编辑图。每次提交独立生成；仅显式参考图才图生图。图下四纯图标；刷新并列最多每行 3 张。不做独立生成中/完成/已提交页。

### R6 星尘

仅发送旁报价；结果区无扣费文案。服务端权威（R8/Q7）。失败未消耗。余额不足保留草稿。

### R7 分享

**弹窗视觉（2026-10-10 按最新设计稿，覆盖旧原型「顶部运营 9:16 配图」）：**

| 区域 | 内容                                                                                                                                       |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 上   | **本次用户已生成好的作品图**（非运营配图）；右上角 ✕                                                                                       |
| 中   | **Admin 运营配置的文案区**（如主标题「分享返还 {rate}」、说明「将同时公开参考图」等；`{rate}` 仍渲染 runtime_config 百分比，无金额占位符） |
| 下   | **唯一主按钮「分享至广场」**（高亮）                                                                                                       |

**不做「不再提示」勾选/按钮**（2026-10-10 · Q11-B，保持 Q1-C）。✕/遮罩只关本次；永久不弹仅在确认分享成功之后。免审即时上架返利。触发见 Q1-C。角标「返 N%」账号首次点分享入口后消失。具体返利金额仅成功轻提示。

### R8 模型与定价

需求 10 模型 Venice 序全量上架（Q8-A）；抽屉仅「名称 + 一句适用场景」。默认 `seedream-v5-pro`（Q4-A）。价：`向上补整十(USD×汇率×倍率×100)`；文生图按 3.12 档、图生图按 edit 固定档（Q7）。改价不影响历史。坏配置 fail closed。Anime 上游 ID 实施前核验映射到 `anime-wai`。

### R9 Admin

模型管理 / 弹窗配置 / 内容标签；草稿→发布→回滚（Q5-B）。弹窗配置页编辑**中部文案**（及预览，含示例作品图示意顶图）；**不提供「不再提示」文案配置**；用户弹窗顶图为真实作品图，不以运营 9:16 配图为准（可不做配图上传）。返利比例不在 Admin。不做内容管理/回答反馈/图片反馈。

## Out of Scope

评论/关注/作者主页；变体/多参考图/蒙版/局部重绘；分享审核文案；回答赞踩；内容管理/回答反馈/图片反馈；AB/通用工作流；自动远端迁移/上生产/提交推送；举报、下架页、返利追回（Q6-C）。

**角色聊天「看看TA」及相关 frontend 会话生图改动**（Q9）：入口已用配置开关关闭，本期不移除代码、不改展示逻辑、不做 pending 收口；不得以本任务名义改会话页。

**与既有图片生成混用**（Q10）：禁止把广场/创作/分享业务挂进既有 `images` 聊天链路（含共用业务 handler、把 attempt 塞进 `chat_message_images`、frontend 复用 `chat-message-image` / `lib/api/images` 作为广场创作入口）。详见 `design.md` 独立模块边界。
