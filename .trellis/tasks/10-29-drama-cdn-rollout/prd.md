# 短剧生产 Bunny 20% 稳定分流与真实等待对照

## 目标

用最小生产分流验证 Bunny 是否降低真实起播和未缓冲快进等待，并能关闭恢复 Supabase。最终要求仍是每次实际等待不超过 5 秒；相对提速不能替代达标。

## 规划时已确认背景（实施前）

用户已认可 20%／80% 稳定分组、相同生产视频／播放器／版本、冻结其他播放优化、12 小时首次检查、失败不抹除及关闭重新取址。当前分支是 `codex/drama-bunny-preview`，现有回源只支持 TEST，生产适配尚未实施。当前诊断包含启动分段和平台，随机会话 ID 不能代表独立用户，启动 observer 不能直接统计后续快进。事实依据见 `research/current-state.md`。

## 需求

- R1：后端基于已鉴权用户稳定分配约 20% Bunny、80% Supabase，跨请求／实例不随机变化；有限样本不要求恰好等于 20%。不新增分组表。两组读取同一生产视频，使用同一播放器、版本和播放策略。
- R2：起播／未缓冲快进分别有观察 ID、平台、原分组、实际路径、真实等待、分段与最终结果。起播从播放触发到实际首帧；自动首页还保留进入 MiniApp 到首帧总时间。主动浏览停留单列。快进从提交目标位置前到目标帧出现，metadata／seeked 不能单独作为成功。
- R3：超过 5 秒继续等待，不调整超时制造达标。失败、退出、切换、后台、缺报和无法验证的帧状态单列；重试保留原失败及关联的累计等待。快照／网络尾报不重复算播放尝试。
- R4：日志不记录原始用户身份、完整 UA、签名 URL 或源凭据。实验专用去重码用于独立用户统计，播放次数／会话数不得替代人数。
- R5：按 iOS／Android／其他平台分别比较起播和快进的尝试数、独立用户、超标次数及比例、受影响人数及比例、失败／退出／未收口，以及每条超标真实时间和主要阶段。不得用平均值／P95 替代逐条超标。
- R6：保留默认关闭的 Bunny 开关。关闭在后端全部实例生效后，新播放重新确认原路径，不消费旧 Bunny 缓存／预取；当前播放不强制中断。连续不可播或明显变慢时可人工提前关闭，不等 12 小时。
- R7：12 小时从生产实际开流计时，先确认没有变差，再判断长尾减少，最后讨论扩大比例。样本不足继续观察；零超标也只证明该批样本。

## 验收标准

- [ ] A1 同用户跨请求／重启／实例稳定分组；鉴权、剧／集归属保持，生产／TEST 回源隔离。
- [ ] A2 私有访问、非法／过期／篡改签名、热缓存、起始／中段 Range 均有功能验证记录；TEST 不冒充生产验收。
- [ ] A3 组别与实际来源一致；两组同版本、同播放策略；关闭后旧缓存／预取／迟到响应不能启动 Bunny。
- [ ] A4 4.9／5／5.1 秒、长等待、失败／退出／切换有真实逐次结果；慢快照与终态只计一次。
- [ ] A5 同用户连续多次播放在窗口内只计一个独立用户；iOS／Android 分开，缺报、未知、截断显式输出。
- [ ] A6 失败后重试不覆盖原失败或重置根计时；快进旧帧不能污染新目标／新资源；只收到 seeked 不算恢复成功。
- [ ] A7 复用现有 `@drama` 验收覆盖路径切换、旧地址、重试和快进；保留集数／位置／暂停状态，遥测失败不阻塞播放。
- [ ] A8 shared 测试、消费者 typecheck、现有相关测试、build／适用 lint 完成；未通过项如实记录。
- [ ] A9 提供生产配置、上线／关闭步骤和首次比较命令。生产启用与真实 5 秒结果须另有实况证据。

## 本次不做

完整 A/B 平台、自动熔断／配置发布平台、新数据库表或迁移、ABR／转码／HLS、播放器性能重构、扩大比例、自动提交推送／合并，以及未单独执行确认的生产配置／发布。
