# 创作与空间一级布局

## 已确认需求

用户要求基于最新 Dev 主项目代码，本地先敲定大布局，不继续离线开发，不上线。五入口顺序已确认：角色、创作、中间抖音式短剧首页、AI短剧广场、我的。角色页共用顶部栏增加“＋创作”快捷入口，与创作页复用同一入口说明。创作上方角色卡为全宽主入口并突出创作权益，图片与视频为下方紧凑次入口；下方我的空间，收藏与我的创作分开，不增加第六个底部入口。

## 范围

仅新建主项目 /creation 入口和空间布局，底栏生成改创作并移到第二项，AI短剧移到第四项；保留 /create 图像广场及其 studio/work URL、原短剧两页。收藏复用已有 API/详情/会话。角色创作暂以可展开的入口说明呈现，布局确认后再接编辑器。我的创作诚实空态，不伪造线上作品。
不接角色发布/审核、AI润色、数据库、计费、收益、私密权限。独立实验稿完整保留。

## 复用与边界

复用 BottomNav / main layout、useFavoritesQuery、CharacterDetailSheet、收藏缓存与原图像广场。新 hub 仅用 Tailwind，无新依赖。当前没有用户创建角色公开契约或所有权查询，不能将离线示例作为主项目作品。

## 验收

手机320/390宽正常；底栏按角色/创作/中央刷剧/AI短剧/我的排序，中央仍直接刷剧，AI短剧仍进目录；角色页“＋创作”与创作页入口使用同一说明弹层；创作入口进入新页，图片视频通道进入原广场；收藏展示/loading/error/empty沿现有 API；我的创作空态有明确位置。仅本地预览。运行 frontend typecheck、针对导航/收藏/角色回流的现有测试及相关 lint；复用 packages/ui-tests fixture 预览，不搭新后端。

## 风险与最小方案

本轮只读展示，无新写入、迁移、LLM、计费或并发；原图像 URL 及返回路径不变。聊天若从空间进入需在现有 source allowlist 增加 space 回流地址（不新建状态源）。新页面故障沿既有 React Query 有限重试与重试按钮。可通过恢复底栏原 href/label 撤下入口，原功能不受影响。预览选择独立空闲端口，不终止其他窗口。

已由 main_creator_contract_review 只读审查实际契约与最小方案，确认 /creation + 复用收藏，不扩展用户创作后台。本轮需求和范围已经用户直接授权。

用户确认大布局，开始细节打磨：角色创作应具有明显高于图片视频的视觉权重。角色创作改为全宽主卡，图片视频压缩为次级行。按产品已确认口径展示：其他用户使用角色卡并消耗星尘，该次消耗40%奖励创作者；创作者使用自己的卡全部模型8折。点击权益可查看文字说明与100→40的简单例子，不增加现金、到账周期、VIP叠加等未确定规则。当前先呈现本地UI，结算/折扣实现需另核对，不能称已经生效。
