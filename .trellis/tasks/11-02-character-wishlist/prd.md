# 角色心愿墙轻量闭环

用户已确认大厅提供许愿入口、创作数据提供找选题入口，已完成本地验收并授权测试通过后上线。

## Requirements

- 大厅许个愿；搜索空态强化入口。创作数据作品表现后、我的创作空态引导查看玩家需求。
- 心愿墙与我的心愿；500字以内自由输入，只支持匿名公开，提交前明确内容所有人可见、不展示昵称和头像。
- 公开心愿可以我也想玩、取消支持、从此创作、关联本人已公开作品；本人可以撤回。
- 作品回应后通知许愿者和支持者，通知进入原心愿查看作品；不承诺一定兑现。
- 复用现有创作和消息中心；不加评论、悬赏、认领、支付及复杂排名。

## Acceptance Criteria

- [ ] 手机入口克制清楚，输入保留失败原稿，返回保留页面状态。
- [ ] 拒绝私密创建；公开DTO不含作者身份；支持/撤回/关联权限服务端校验。
- [ ] 支持和关联重试幂等；角色公开成功但关联失败可重试关联，不重做发布。
- [ ] 关联作品符合公开审核状态；改私密或下架后不再在公共墙展示。
- [ ] 本地固定场景覆盖许愿、支持、匿名公开说明、作品回应与错误状态。

## Android/iOS 性能 P95 门禁

新页面无线上基线，不伪造样本。页面目标2500ms，接口目标1500ms；本轮移动验收使用本地模拟，不声称实机P95。后续上线按平台采样24小时，样本不足明确记录。入口仅链接，不额外请求心愿数据。
