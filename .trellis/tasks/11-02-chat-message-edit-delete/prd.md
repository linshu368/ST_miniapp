# 最近十轮消息编辑与单条删除

用户已明确要求实施，并确认：一问一答为一轮，从最新往回十轮；只删除所选单条，保留后续。用户与角色消息均可修改，分支保留原有逻辑。用户在本地验收后已授权本批上线；先dev验收，再仅将本功能发布main。

## 验收

- 服务端和前端均限制最近十个逻辑轮次，开场白不开放。删除不重排轮次，不因删除反复向前解锁。
- 删除内容不再出现在当前聊天及下一轮上下文；编辑后后续生成使用新文字。未选择的消息不改，不自动生成或扣费。
- 原有分支不受源聊天改写影响；新分支继承点击时的有效内容，包括已编辑与删除状态。
- 就地编辑、保存/取消、保存失败保留草稿；移动键盘和窄屏可操作，不跳到聊天底部；生成中不可修改。
- 保留原生成、计费事实，只修改会话可见内容；不承诺供应商缓存必然命中。
- 复用固定本地验收。迁移、权限、十轮边界、分支隔离属于必须回归的风险。

## 最终入口与编辑范围

- 角色回复：底部左侧保留语音和更多，右侧依次为编辑、重新生成、点赞；更多菜单收纳分支和删除。
- 用户消息：底部更多菜单收纳编辑和删除，不单独露出编辑图标。
- 删除在原位出现“确认吗？/取消/确认”，只删所选消息。
- 角色编辑仅显示正文；选项、状态、记忆等附加内容由服务端原样保留。

## 追加：同角色多对话辨认（仅前端）

用户授权轻量展示改善，避免会话存储或分支行为变化。角色名集中在抽屉顶部；默认会话名用固定创建日期时间兜底，自定义名保留；显示当前会话、分支起点和已有预览；管理操作收入更多。默认标题不回写，不新增接口、数据库或生成调用。
