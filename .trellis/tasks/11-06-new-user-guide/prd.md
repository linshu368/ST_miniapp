# 新用户渐进式角色体验引导

## 目标

帮助新注册用户尽快完成第一次有趣的角色互动，再理解平台特色：编辑最近10轮自己的话/角色正文控制剧情；从中途分支到独立新对话，原对话保留。主线为选角色→开聊→理解编辑与分支→找回对话。

## 约束

移动端390/320；原生页面内轻提示，非强制遮罩/逐页点下一步；随时跳过；不自动发送、收费、编辑或创建分支。输入/生成/编辑时不展示打断。旧用户不因本地缓存为空而收到新手教程。首次符合24小时注册且不足10轮者可入组，7天自然过期；本设备按账号保存进度。生产只读调研，本次只本地开发，不发布。

## 验收

- 老账号/资格接口失败不出教程，新账号只在主线页面展示；首屏不等待资格读取。
- 发现页一个轻量开场；进入对话解释自由输入；成功回复后再提示编辑和分支，点击后才展开说明。
- 编辑与分支说明和实际入口一致，编辑最近10轮、仅正文；分支保留原会话。找入口动作只打开现有工具，不触发写入。
- 完成/跳过刷新仍记住；换角色不重启；返回发现可找到对话。
- 复用本地验收fixture，覆盖新/老/失败/刷新/跳过/窄屏/真实工具入口衔接；原聊天编辑分支回归。

## 本轮产品确认

首次发现默认推荐；编辑/分支说明简短直白；首次开聊提供展开回复偏好的按钮，不介绍内部细节，不变更设置。既有用户浏览选择和返回保序不变。
