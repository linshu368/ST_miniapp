# Surplus Intelligence 完整接入与调用明细落库

## 用户目标

完整支持仓库现有聊天流程使用 Surplus Intelligence，新增 `surplusintelligence_chat_history` 记录其调用参数与响应数据。会话及消息数据继续保存在 `chat_history`。

## 需求与边界

- 支持模型目录同步、配置草稿/发布/回滚、模型选择、流式/非流式生成、首字竞争、显式停止、超时和既有计费恢复。
- 调用记录覆盖实际发出的 Surplus 请求，包括最终由 OpenRouter 兜底交付的 Surplus 失败/取消调用。
- 参数反映实际发出的非正文参数；默认值未知时不得伪造 temperature/top_p/max_tokens。保存调用身份、HTTP 状态、结束原因、token、可用真实成本和时延；未返回的数据保持未知。
- 提示词、回复与思考正文不复制到明细；密钥、鉴权请求头、任意原始错误正文不得写入明细或日志。
- 保留固定档位收费、免费额度、VIP、创作者收益和取消/停止语义；成本观测不成为新的扣费权威。
- 兼容 OpenRouter、Venice 及旧数据；辅助审核/润色不创建虚构聊天父行。不扩展为新参数编辑器、供应商路由后台或其他媒体产品。

## 验收标准

- [ ] 数据库模型目录校验接受 surplus，未知 provider 拒绝；草稿、发布和回滚继续可用。
- [ ] 正常发送/重生成经过登记、请求、ID 保存、终态、交付及结算，不误写 Venice。
- [ ] 新表关联父轮次并级联删除；匿名/登录用户无直接读写权限；同请求幂等，不同身份/参数冲突拒绝。
- [ ] 流式/非流式均记录实际非正文参数及有界响应元数据；流式明确请求 include_usage；0 与未知严格区分。
- [ ] Surplus 输给 OR 兜底仍保留自己的调用事实，最终交付及一次扣费归胜者。
- [ ] 缺 key、4xx/429/5xx、中断、空回复、缺 usage/ID/结束原因、停止/取消/超时有明确行为，不重放收费生成。
- [ ] ID 写入未知先读回；迟到结果不覆盖身份、取消或已确认供应商事实；重复/并发结算不重复收费。
- [ ] 旧 surplus snapshot-only 行可恢复；无 OpenRouter key 不影响 Surplus；供应商观测缺失不阻塞固定报价结算。
- [ ] 通过针对性单测、隔离 PG17/PostgREST 回归、consumer typecheck、适用 build/lint；不可执行项明确记录。
- [ ] 交付迁移/发布/恢复说明，不自动执行远端迁移或生产配置写入。

## Android/iOS 性能 P95

影响 `/chat/[characterId]` 生成链路。无可见真实样本，双端页面加载及接口首字 P95 基线均为 null。工程目标：页面加载 P95 3000ms、SSE 首字 P95 6000ms；目标不代表已达成，不把首字 SLA 改为硬取消。发布前后分别观测同模型/同版本各 24h，Android/iOS 分开采样；低样本明确 unknown。
