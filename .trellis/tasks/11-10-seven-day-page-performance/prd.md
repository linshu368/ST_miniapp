# 近七天生产页面性能审计

## 需求

只读核对 2026-11-03 16:20:05 至 2026-11-10 16:20:05（Asia/Shanghai）的 MiniApp 页面性能，结合 Grafana、Sentry、Railway，列出各页面 Android/iOS P95、样本量、失败、卡住和接口超时证据。

## 约束

- 不修改产品、生产配置、告警、部署或数据库，不读取数据库业务行。
- 导出仅保留聚合、归一化路由与公开监控链接，不保存原始日志、用户标识、IP、密钥或正文。
- 区分站内导航、文档冷启动、挂载到可用、自动 pageload span、服务端及客户端接口；不同来源不合并样本。
- P95 仅统计成功前台样本，并列终态与卡住；N<100 标低样本，缺样本不补零。
- Sentry production 标签中存在 Preview URL；不直接等同正式域名。当前可见错误最早为 11 月 6 日，不证明前三天无错误。

## 验收标准

- [x] 核对生产项目、服务、环境，查询三方实时只读数据。
- [x] 覆盖 27 个登记业务路由及根入口记录；列出运营后台监控缺口。
- [x] 列出 Android/iOS 导航与冷启动 P95/N，补充无导航样本页面的挂载数据。
- [x] 区分慢告警、真实异常、客户端超时及主动取消。
- [x] 完整分页核对 Railway 525 条 5xx，保存脱敏聚合及查询限制。
- [x] 交付 report.md 和 evidence.json；不新增测试或产品代码。

## 性能门禁

不适用于实现变更：本任务仅只读审计，不改变页面或 API。Android/iOS 实测基线在报告按路由列出，既有导航目标为 2000ms；本任务没有发布步骤。

## 执行与复核

复用现有 Grafana 页面及 API 面板、page-tracker/route-template 契约、Sentry Metrics/错误聚合和 Railway HTTP 统计。使用有界只读聚合，无新采集组件、数据库对象、运行时 API 或依赖。复核时间窗、单位、样本量和 Railway 分页总数；无需产品测试或构建。没有远端写入，无发布或回滚步骤。
