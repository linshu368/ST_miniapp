# 畅聊栏目（免费模型）第一版

## Goal

在对话页「引擎选择」面板里，轻量/标准/旗舰三档的上面加一个「畅聊」栏目。栏目开放时，里面的模型 0 星尘、不限次数，作为福利让用户多用。模型全部来自 Surplus 的低价池，由系统按规则自动上架、下架：**免费模型是福利，不是糟糕模型**。

开放规则分阶段，第一版是**整周免费**，先看数据效果。使用范围（所有角色卡，还是只有自己创作的卡）还没定，做成运营参数。栏目对所有角色卡都显示：范围限定在自己的卡时，别人的卡上照样显示栏目和规则，起宣传作用，鼓励用户自己做卡。以后可能加「每周固定几天」，第一版不做。

## 用户已确认的决定（2026-11-11）

### 展示

- 方案 B「主推卡」：色条「畅聊」、标题「免费畅聊」、顶栏胶囊「畅聊引擎」。
- 颜色：烛光金，开放时调亮一档。
- 原价划线必须有；模型名旁边标「对标档位」（旗舰/标准/轻量）。
- 卡头有规则文字，最多显示三行，在运营平台填写。
- 状态只有两种：
  - **开放**：写结束时间，比如「明天 02:00 结束」；
  - **未开放**：栏目默认折叠，可以点开预览，但不能选。时间标签按原因显示：
    - 福利期还没开始：「<时间> 开始」；
    - 范围只限自己的卡、当前是别人的卡：「仅限自创角色卡」；
    - 一个在架模型都没有：「暂未开放」。
- 不区分 VIP 身份。
- 旧的「限量免费」（`is_free` 角色卡免费轮次）以后不用了，本栏目不复用它，也不改动它。

### 选模

- 只用 Surplus 上标为 trusted 的供应商。
- 兜底继续用 1017。
- 本模块不设每日预算，也不设单轮成本限制。控制成本靠两点：一是你选候选池时就避开贵模型，二是请求带 85% 折扣底线。
- 第一版**不做后台拨测**。

## Requirements

### R1 候选池与生命周期

- 候选池由运营在运营平台维护。每个模型配置：Surplus 模型 id、显示名、介绍语、**系列**（比如 deepseek、gemini）、**对标档位**（划线原价取这一档当前的星尘价）。
- 每个候选模型处于三种状态之一：未上架、在架、冷却中（刚被下架）。
- 评估任务**每 30 分钟**跑一次，所有候选模型一起评估：
  - **未上架**（且不在冷却期）：用 Surplus 官方数据初筛，连续达标 N 次（默认 2）就上架，同时选定供应商。
  - **在架**：同一时间只用一家供应商，选定后一直用（保缓存命中）。两路检查任意一路越线，就按同一套规则顺延到下一家达标供应商；所有达标供应商都用不了才下架。
    1. 官方数据复核：已选供应商还满足初筛门槛吗？
    2. 真实业务数据：见 R3。
  - **冷却期**：按下架原因区分。
    - 官方数据原因：默认 2 小时。
    - 业务数据原因：默认 24 小时；7 天内再被下架，依次升到 72 小时、7 天。
    - 冷却期满后回到「未上架」，重新走初筛。
- 遇到「数据缺失、平台接口失败」时：上架不过，在架的模型保持现状、不下架。不因为 Surplus 接口一时挂了就把整栏清空。
- 每一次上架和下架都记录原因和当时的指标，方便复盘。

### R2 官方数据初筛（也用于在架复核）

数据只取 Surplus 公开接口。所有门槛都放在运营平台；门槛留空表示不检查这项。

| 参数                                       | 默认初值   |
| ------------------------------------------ | ---------- |
| 折扣底线（同时用作请求时的底线）           | 85%        |
| 达到底线、可用且健康的报价数（按供应商算） | 5          |
| 7 天实际成交折扣                           | ≥ 折扣底线 |
| 成功率（供应商 24 小时）                   | 95%        |
| 首字 p50 / p90                             | 3s / 7.5s  |
| 出字速度 tps_p50                           | 30         |
| 供应商 24 小时最少样本                     | 200        |
| 价格分档倍数（选供应商用）                 | 3          |

- 只看 trusted 供应商。先列出所有达标供应商，每家的价格取它达标报价里最便宜的一个，然后按下面的规则挑一家：
  - 和最便宜的那家价格差不到「价格分档倍数」（默认 3 倍）的算同一档，在这一档里选首字 p50 最低的；
  - 贵出 3 倍以上的单独一档，只有便宜档一家都没有时才考虑；
  - 已经在用的那家只要还达标，就一直用，不因为别家更快而换。
- 在用的那家不达标（官方复核），或者在我们自己的流量上业务越线，就按同一套规则换下一家。业务越线的那家先排除一段时间（默认 24 小时，否则官方数据还说它好，又会被选回来）；换了供应商以后，业务指标从换的那一刻重新统计。
- 请求只发给当前这一家（Surplus 的 `provider` 白名单只放一家）。

### R3 在架的真实业务数据

按「模型」统计最近一个窗口的数据，参数都在运营平台，留空表示不检查。

| 指标                     | 含义                                                                      | 默认下架线 |
| ------------------------ | ------------------------------------------------------------------------- | ---------- |
| 没出字率                 | 主模型这一轮一个字都没出（超时、供应商报错、凑不到折扣返回 404 等，都算） | 10%        |
| 兜底交付率               | 最后交给用户的是兜底模型写的回复                                          | 15%        |
| 超时率                   | 用户最后什么都没收到                                                      | 2%         |
| 真实首字 p90（主模型）   |                                                                           | 7.5s       |
| 拒答率 / 截断率 / 点踩率 |                                                                           | 留空       |

- 窗口默认 24 小时，至少 50 轮才判断；样本不够时不判断。

### R4 观察指标（只展示，不触发下架）

指标放在 **Grafana**，加到现有模型相关看板里合适的位置；运营平台只用来调参数。

- **每次成功出字调用的平均实际价格**：统计窗口内，这个模型所有主模型出过字的 Surplus 调用，实际扣费总额 ÷ 调用次数。分模型、分供应商、按天看趋势。
- 旁边同时显示平均输入长度，用来区分涨价是因为对话变长，还是因为缓存命中变差。
- R3 的各项业务指标也在同一组面板里展示。
- 每个模型的当前状态、白名单供应商、上下架记录也放进 Grafana。

### R5 开放规则与时间（第一版）

- 运营平台参数：
  - **福利期**：开始时间、结束时间，必填。结束时间就是开放时显示的「<时间> 结束」，要延长就改这个时间。
  - **使用范围**：所有角色卡，或者只有自己创作的角色卡。
  - **总开关**：关掉以后栏目整体隐藏。
- 后端按「用户 + 角色卡 + 当前时间」算栏目状态：
  - 开放：在福利期内、这张卡在使用范围内、而且至少有一个在架模型。
  - 未开放（按原因分三种，见「展示」）：福利期还没开始 / 别人的卡（范围限自己的卡时） / 没有在架模型。
  - 隐藏：总开关关了，或者福利期已经结束。
- 每周时段规则以后再做。

### R5.1 选择按用户存

现有逻辑就是按用户存（不是按角色卡），保持不变。范围限自己的卡时，用户在自己的卡上选了免费模型，再去聊别人的卡，按 R6 自动换回 1017；回到自己的卡要重新选。

### R6 选择、生成与扣费

- 开放时可以选栏目里的模型；后端在切换和每一轮生成时都会重新校验是否开放。
- 免费模型的首字时间：
  - 主模型等多久还没出字就启动兜底：默认 4 秒；
  - 首字总上限：默认 7.5 秒。
  - 两个都放在运营平台，只对免费模型生效，付费档不变。
- 发给 Surplus 的请求带上折扣底线（`X-Min-Discount`）和供应商白名单（`provider`）。
- 扣费：免费模型的轮次扣 0 星尘，单独记成「畅聊」这一类，和旧的免费轮次分开统计。兜底交付的轮次对用户同样免费。
- **自动换模型**：用户当前选的免费模型不能用了（被下架，或者对这张卡、这个时间不开放），下次打开面板或发消息时自动换掉：
  - 优先换同系列的在架免费模型；
  - 同系列没有，就随机换一个在架免费模型；
  - 栏目里一个都不剩、或者栏目不开放，就换回 1017。
  - 换的时候不弹任何提示，面板里也不提示；运营在公告里统一说明。

## Out of Scope

- 后台拨测（第二版再做）。
- 每周时段规则。
- 运营平台里的指标页面（指标看 Grafana）。
- 每日预算、单轮成本限制。
- 下线旧「限量免费」机制，另开任务。
- 按卖家屏蔽：Surplus 不开放到卖家这一层。

## Acceptance Criteria

- [ ] 总开关关闭时，面板、顶栏、扣费都和现在完全一样。
- [ ] 评估任务：候选模型满足门槛并连续 2 次达标后上架，按价格分档 + 首字规则选定一家 trusted 供应商；在用的那家还达标就不换；不达标或业务越线就顺延下一家，全不行才下架、进入对应冷却期；Surplus 接口失败时在架模型保持不变。每一次上架、换供应商、下架都有记录。
- [ ] 开放规则：
  - 福利期内、范围是「所有卡」：任何卡都开放，显示结束时间；
  - 范围是「自己的卡」：自己的卡开放；别人的卡显示「仅限自创角色卡」，不能选；
  - 福利期还没开始：显示开始时间；
  - 没有在架模型：显示「暂未开放」；
  - 福利期结束或者关掉总开关：栏目隐藏。
- [ ] 选择免费模型后发消息：请求带折扣底线和供应商白名单；扣 0 星尘、记为畅聊类；兜底交付也是 0。
- [ ] 模型被下架以后：按「同系列 → 随机 → 1017」自动换模型，不弹任何提示。
- [ ] 首字参数只对免费模型生效，付费档的首字和兜底行为不变。
- [ ] 在 Grafana 能看到：平均实际价格、平均输入长度、R3 的各项指标、模型状态和上下架记录。和评估任务用的是同一套口径。
- [ ] 测试（用户已同意）：评估和扣费的纯函数单测；`@free-zone` 本地自动验收组。
- [ ] 前端在 390/320 宽下两种状态都正常显示（见 design 的 UI 部分）。
- [ ] typecheck/lint/test/lint:complexity 通过；迁移在 TEST 执行验证过。

## Android/iOS 性能 P95 门禁

- 受影响页面：`/chat/[characterId]`。
- 受影响接口：`GET /api/v1/models/config`（新增栏目计算，读内存缓存，不额外查库）、`POST /api/v1/models/select`、对话生成接口（只有选了免费模型的用户首字上限放宽到 7.5 秒）。
- Android / iOS 页面加载 P95：基线 null（没有可见样本）/ 目标 2500 ms。
- 接口 P95：models/config 基线 null / 目标 1000 ms。
- 数据来源与观测窗口：本地 ui-tests；发布后 24 小时看已有的接口日志、首字统计和前端遥测。
- 说明：首屏没有新增请求。免费模型首字变慢是有意的取舍，由 R3 的指标约束。没有样本的地方保留 null。
