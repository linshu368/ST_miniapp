# 生产慢页面与失败恢复整体优化

## 目标与授权

依据 `../11-12-overnight-page-performance/slow-pages-optimization-design.md`，处理13个慢页面的可证实公共等待、入场请求竞争与错误恢复。用户在阅读方案后明确要求“开始进行整体优化处理”，授权本地实现和验证；不授权生产配置、迁移、发布或Git提交。

## 范围与不变量

- 覆盖大厅、聊天、个人中心、短剧详情/放映/剧场、消息列表/详情、影像广场、角色编辑、创作数据、客服、心愿列表。
- 优先修复请求槽等待未纳入期限、正文首包低优先级、新建会话缓存重复读取、Android深层导航旁路争抢和大厅代理失败形状。
- 保留真实ready/首帧定义、内容、分页、身份/私密缓存、公告新鲜度、未读/已读语义、草稿、创建及生成计费行为。
- 复用最新origin/dev已有的全局不重复重试、媒体缓存和新功能；不重做已上线优化。origin/main额外入口上报只检查兼容，不覆盖。
- 不新增数据库对象、外部依赖、服务、公开HTTP端点或新的遥测出口；不根据报告中低样本直接调整并发帽/超时预算或全量预热。

## 验收

- [x] 并发槽排队及正文消费均在明确期限内；过期队列不派发，离页取消不重试，保留有限安全读取重试和长操作bypass。
- [x] 前台正文请求优先于预热/未读等工作；同一key预取不额外放大HTTP，不延长数据新鲜度。
- [x] 新建会话复用服务端已确认的完整首屏数据；已有/失效会话仍正确回读和恢复，创建不自动重试。
- [x] Android已登记深层Link/返回可复用导航让路，错误/成功/兜底均能释放，旧导航不能释放新导航；iOS行为保持。
- [x] 大厅代理失败返回现有shared envelope且不缓存，取消/超时/上游失败可区分；有效公开latest缓存、推荐隔离不变。
- [x] 适用Frontend typecheck/tests/lint/build、复杂度、UI固定流程通过；跨包/部署改动按spec执行额外校验。无生产样本时不声明P95达标。
