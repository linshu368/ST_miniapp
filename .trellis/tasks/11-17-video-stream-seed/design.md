# 设计

复用 video-seed-import 的表格解析和六模型映射、video-media 的首帧和缩放参数、原 TEST seed 的内容寻址封面路径及私有 Storage 语义。短剧 Stream 的 UID 与签名 HLS 模式用于验收，独立处理队列，不触碰短剧配置和 webhook。现有 import_video_seed_work 只适用于 MP4 消费端，生产未部署视频基线与相应私有桶，实际发布 SQL 须绑定后续代码确认的产物契约。

生产数据为 media_plaza × E。现有 video_artifacts 与 image_plaza_works 由审核后的 seed 迁移写入，跟随作品生命周期保留，引用私有封面对象和 Stream UID。本任务 SQL 在临时表中准备输入和回执，不改变线上 schema 或永久对象。以 source_video_id 关联，迁移生成要求已核验回执，源视频 URL 仅用于溯源。无跨域计费或用户写入。

下载有超时、200MiB 限制、有限退避，下载和 FFmpeg 设置并发预算。封面内容寻址，不覆盖已有对象，重复时比对字节 SHA256。状态按 ID 独立持久化，重启复用已验证产物。Cloudflare 批量前确认账户、可用配额与样本签名播放。提交超时的任务需按标记查找，防止重复创建。SQL 在单事务中预检环境、依赖和回执；失败不发布。应用发布后再导入真实回执，旧 mp4 路径由后续播放代码保留。发现异常停止继续批次，按已记录 ID 审查恢复，保留媒体便于复验。

本批是离线资产与交接，没有线上页面/API 改动；HLS 播放代码开发与 Android/iOS 首帧、快进 P95 继续由父任务负责。批处理记录终态、状态码、计数、耗时和来源 ID，不记录完整 URL、提示词、签名或凭据。无在线告警新增。
