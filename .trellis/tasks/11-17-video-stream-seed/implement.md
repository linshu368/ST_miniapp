# 实施与验证

1. 运行仓库 video-plaza:seed dry-run 对表，再导出通过校验的全量行。
2. 并发准备首帧，抽查 FFmpeg 输出；经 Storage API 校验私有桶，相同路径读取校验 SHA256。记录限流、来源失败、解码失败和上传重复。
3. 校验 Stream 账号及配额，小批上传和核验签名主清单、变体和分片后扩大。未知写入结果保留为待查。SQL 使用已核验 UID 和封面，不连生产库写入。
4. SQL 在本地 PostgreSQL 兼容引擎演练数据形状、重复 ID、缺回执和事务终止。生产库结构通过只读 catalog 预检。正式发布消费端验证由父任务覆盖原生 HLS/hls.js 和旧 MP4。
