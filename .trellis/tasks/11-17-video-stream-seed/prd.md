# 表格视频导入 Cloudflare Stream

- 使用翻译表中的 5,082 个视频条目，按 ID 对照原表恢复视频 URL，保留原文、译文、模型和热度。
- 视频进入短剧同类的 Cloudflare Stream 签名 HLS 分发，封面取源视频首个可解码画面并写入 main 的私有 media-plaza-video 桶。生产应用上线之前交付 SQL 和验证记录。
- 验收依据为逐条已核验首帧、稳定 Stream UID、就绪签名 HLS 与分片。生产数据库执行留给后续代码发布，按正式迁移流程单文件操作。
- 源视频返回 404 时按用户确认跳过并留下来源行号。其他失败先恢复和复验。
