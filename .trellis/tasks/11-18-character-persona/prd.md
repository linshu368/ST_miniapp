# 角色设定与主角人设

## Goal

用户反馈"没有编辑人物设定的功能"。让用户在角色卡原有设定之外：

1. 给**某一张卡**补充自己的设定（可写多个人物，只对这张卡生效）；
2. 维护自己的**主角人设**库，并按卡选用（默认人设 + 每张卡可改选或不使用）。

同时按用户确认精简聊天页的几处冗余入口。交互稿：https://claude.ai/artifact/FsTfP3zwCdUrdcvPX9H7uy

## Requirements

### 功能

- 补充设定：每个用户 × 每张卡一段文本，≤1000 字。
- 主角人设库：每用户最多 10 个，名字 ≤20 字（仅用户自己区分，不进 prompt）、描述 ≤800 字；至多一个默认；第一个自动成为默认。
- 每张卡的人设选择：跟随默认 / 不使用 / 指定某个人设。删除被选用的人设后，该卡回到"跟随默认"。
- 人设只加描述，称呼仍用用户昵称（`{{user}}`），**不**替换名字。
- 设定从保存后的**下一轮**生效；重新生成用最新设定。同一角色的所有会话共用。
- 设定在记忆压缩、历史截断后必须仍然每轮带上（它不属于历史）。
- 入口：聊天页工具箱「对话设置」里新增一行「角色设定」，二级页内完成选人设（在上）、补充设定（在下）、新建/编辑/删除人设。不新增"我的"页入口。

### 精简（用户已逐项确认）

- 删：工具箱「图片设置」标签页、工具箱底部"模型选择已移至…"虚线提示、回复偏好条上的"状态栏 · 记忆栏 · 可选项"摘要、聊天页顶栏右上"评论"图标。
- 保留：回复模块旁的"展开/收起"小按钮、顶栏收藏心形。
- 回复偏好里的"我的偏好"改名"文风偏好 · 所有角色"，避免与新的"补充设定"混淆。
- "开启新对话"移出工具箱，放到左上角"对话记录"侧栏顶部右侧的「＋ 新对话」。
- 工具箱「玩法小贴士」扩充为聊天页里一眼看不明白的功能说明：大白话、每条一句解释 + 一个例子；运营可配置的档位名不写死。
- 示例文案面向成人向产品，可以暧昧但不露骨；不用"小红/小明"这类名字，人物一律成年。
- **只改上面讨论过的新增与删除项**，其余部件（深度思考、收藏、展开/收起、侧栏列表等）沿用线上。

### Prompt

- 在角色卡之后、会话记忆之前加一条独立 system 消息：「用户补充设定」「主角人设」两段，空段不出现，两段都空则整条不出现（对现有用户 prompt 字节级不变）。
- `{{user}}` 在组装后统一替换，用户在设定里写 `{{user}}` 也生效。

## Acceptance Criteria

- [ ] 两段都空时 buildPrompt 输出与改动前完全一致（测试）。
- [ ] 顺序固定：角色卡 → 用户设定 → 会话记忆 → 历史 → 本轮；压缩/截断前后用户设定那条消息原样存在（测试）。
- [ ] 超长、超过 10 个、改别人的人设均被服务端拒绝。
- [ ] 删除人设后选用它的卡回到默认；删默认后不再有默认（用户可重新指定）。
- [ ] 首字耗时无可测退化：设定读取并入准备期并行读取，单次主键查询。
- [ ] 前端精简项全部落地，工具箱二级页与现有"默认声音"进出方式一致。
