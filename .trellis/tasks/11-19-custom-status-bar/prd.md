# 用户自定义状态栏

## 背景

现在的状态栏规则（运营配置 `status_rules` v6）对所有角色卡、所有用户一样：只要求"面板 + 字段：内容"，具体追踪什么由模型自己定。用户希望不同角色、不同用户看到自己在意的状态（如"亲密度"），并能写清这项状态是什么意思。

## 需求

1. 创作者只写**内容**：要看哪些状态、每项是什么意思。不接触正则、HTML、富文本。
2. 后台定义好格式：模型输出格式、解析正则、渲染方式，以及用户内容到这三者的对应关系。
3. 每轮前置 prompt 里按用户的定义描述格式，保证每轮生效。
4. 状态栏模板像主角人设一样可复用：建一次，多张卡可选用。
5. 不能出错：模型写歪时不露标记、不吞正文，最差退化为普通文字。
6. 允许重构现有状态栏。

## 本阶段范围（2026-11-19 用户指示）

先定格式、正则、渲染、对应关系与 prompt 写法；UI 和交互暂不做。

第一版只开放给创作者：建卡/编辑卡时作为一个栏目插入，状态栏随角色卡走；普通用户暂不能自定义。

篇幅约束针对的是每轮系统指令里描述状态栏的**规则**，不是状态栏输出；输出长短不限（默认折叠）。

## 验收

- design.md 给出：用户可定义的字段、输出格式、解析规则、渲染映射、prompt 生成规则与全文示例、出错兜底、兼容与上线顺序。
- 解析规则有可运行原型，覆盖常见跑偏写法与恶意输入耗时。
