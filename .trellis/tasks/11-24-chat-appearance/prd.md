# 聊天背景、字号与昼夜模式

## 目标

补上三个基本的 App 能力，并且不增加聊天页的常驻按钮：自定义聊天背景（含采光）、正文字号、昼夜模式。技术方案见 [design.md](design.md)，执行计划见 [implement.md](implement.md)。定稿原型（离线单文件，交互与尺寸以它为准；原型里现有部件只是快照，以线上为准）：`ST_miniapp/labs/appearance-prototype/聊天外观与昼夜-原型.html`。

## 需求（用户 11-24 已定）

1. **位置**：只影响聊天画面的（背景、采光、字号）属于低频设置，收进工具箱，单开第三个标签「界面设置」；昼夜影响整个 App，放「我的」页头铃铛旁一个图标。
2. **昼夜**：只有夜间、白天两态，点图标直接切，不弹菜单、不写字、不弹提示。默认夜间。不做「跟随 Telegram」（后续要做独立 APP 和网站）。
3. **聊天背景**：来源四种——无、封面（角色自己的封面）、用过的图、相册。选完立即生效，没有裁剪和保存。范围二选一：仅此角色 / 全部对话，默认仅此角色；单独设过的角色不受「全部对话」影响；「全部对话 + 封面」时每个角色用自己的封面。
4. **采光**：一条滑杆，左端看清字、右端看清图。选图后自动给起点；图太亮太花时字下自动垫底，保证读得清。夜间、白天各记一个值。
5. **字号**：字体、颜色、样式、默认大小全部沿用线上；保留滑杆，按原型五档调大小（用户 11-24 确认）。
6. **少字**：一看就懂的东西不加解释、档位名和成功提示。
7. 工具箱现有的标题、说明、两个标签和四张卡片不动。
8. **收文案**（用户 11-24 追加，取代第 7 条里「说明不动」的部分）：面向玩家的长段解释删掉，或收进小问号、输入框占位；不要 AI 腔。重点是工具箱，其他页面有则改之。创作者建卡、数据看板不在范围。涉及扣费、隐私、删除后果的说明保留。

## 验收标准

- [ ] 聊天页没有新增常驻按钮；工具箱第三个标签里能完成背景、采光、字号的全部操作。
- [ ] 没动过设置的老用户，夜间各页面与上线前逐像素一致（ui-tests 截图比对）。
- [ ] 白天模式下所有页面正文对比度 ≥ 4.5:1；剧场与放映、角色封面及压在封面上的角标、VIP 卡、增长礼券、开屏保持深色。
- [ ] 选过白天的人冷启动第一帧就是白天，不闪黑；切换后 Telegram 顶栏、底栏颜色一致。
- [ ] 角色回复（含选项卡、对白）在白天模式下用运营 CSS 已有的浅色值，不改运营后台。
- [ ] 换图即时生效；重启 App 仍在；仅此角色 / 全部对话 / 单独设过的优先级正确；先点全部对话又改回仅此角色，原来的全局背景还原。
- [ ] 任意图片、任意采光下，正文和对白对比度 ≥ 4.5:1。
- [ ] 打开界面设置时背后不模糊不压暗；拖滑杆时面板隐去只留该条；下滑、点外面、返回键都先收面板。
- [ ] 键盘弹起、切换会话、生成中，背景不缩、不跳、不闪；不影响发送、滚动贴底、状态面板。
- [ ] 五档可调，正在读的那段不移位；选项按钮热区始终 ≥ 44px；输入框不因大字号溢出。
- [ ] 存储不可用、图片损坏、存满时不影响聊天；失败只提示一句。
- [ ] 320px 宽无横向溢出；「减少动态效果」下无位移动画。

## Android/iOS 性能 P95 门禁

- 受影响页面：`/chat/:id`（背景层、面板）、`/profile`（图标）、`/characters`、`/chats`（白天配色）。无接口改动。
- 站内导航 P95 基线（ready、foreground、spa、production，截至 2026-11-24 的 48 小时）：
  - `/chat/:id`：Android 3829 ms（N=909）、iOS 3385 ms（N=124）
  - `/profile`：Android 2807 ms（N=773）、iOS 791 ms（N=137）
  - `/characters`：Android 1787 ms（N=523）、iOS 1283 ms（N=92，样本少只看方向）
  - `/chats`：Android 1888 ms（N=549）、iOS 1386 ms（N=100）
- 目标：全部不劣化（+5% 以内）。背景图在页面就绪后才读取，不在进页关键路径上。
- 发布后：按新 release 等长 48 小时同口径复查。

## 不做

跟随系统或 Telegram、换字体、图片裁剪与虚化、图片上传与跨设备同步、背景市场、按会话单独设背景、剧场白天版。
