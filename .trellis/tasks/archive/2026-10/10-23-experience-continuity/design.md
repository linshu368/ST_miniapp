# 设计与规划门禁

## 复用调研

复用 ChatComposer、ChatMessageList、ChatSessionDrawer、FavoriteButton、favorites mutation/cache、useChatSession/useConversationTurn、已有 lobby-return/roleplay-navigation、RecentConversationCard。角色试卡只扩展现有 UI 正向标记和返回文案，不新增服务器状态源。
影像复用 image-plaza query/history/quote/submit/share、StudioArtifactCard、StudioSettingsDialog、Telegram 下载 helper；广场与工作室共享一个轻量历史 Sheet。浏览恢复只存 UI 标量/ID，不复制 DTO 或分页游标。
新增一个非持久 composer draft store/hook，消费既有 Zustand，按用户+模块+会话隔离，有限数量/短生命周期；不落盘、不上报、不自动提交。草稿 hook 提供 value/setValue/hasDraft/clearIfUnchanged；空草稿与无草稿区分。

## 可靠性

- 草稿与异步请求身份必须绑定会话；用户继续编辑后，旧提交成功不能清掉新内容；失败可恢复但不能把可能已受理的请求自动重发。仅保存文本，不存参考文件/blob/initData/支付URL。
- 相同角色收藏共享 pending、防重复；不同角色并发失败只回滚本角色，最后一笔完成后精确刷新。提示宿主独立于卡片，防乐观卸载时丢失错误；只做收藏专用临时提示，不建通用消息框架。
- 生成状态查询失败只重读；报价、提交、idempotency_key、现有超时与有限重试保持。再生成不清新草稿，提交反馈准确，不伪造进度/预计时长。
- 消息与列表位置尊重用户滚动；只有用户点击/主动提交才恢复跟随；更新或缺锚点安全降级，用户开始操作立即停止自动恢复。
- 已聊标记只来自已加载且确有用户轮次的有效历史，未命中不声称未聊；退出不等于不喜欢，不增加负偏好。返回不暗示已取消后端生成。
- 无新服务端写路径、事务/迁移/容量服务或外部 SDK。下载沿既有权限与短期 URL，不把正文或 URL 写日志。

## 最小充分方案

不引入依赖、云草稿、AI起标题、新推荐/筛选体系、自动清理/跳转。共用现有 API 和组件，新增仅草稿 store/hook、影像历史 Sheet/返回 helper、必要收藏短提示。快速 Splash 保留加载/错误，去掉 ready 后固定长等待。

## 演进与恢复

仅前端，可按文件组回滚；保留全部原有路由和真实 API，不迁移数据。遇到跨会话草稿串用、重复付费提交、错误回滚覆盖其他收藏、返回丢现场或小屏遮挡则停止演示并修复。原有未提交导航/回复偏好成果须保留。

## 可验证性

测试计划认可新增草稿隔离/条件清空的回归测试；在现有收藏/影像/导航测试内扩展相关风险用例，不为纯布局创建镜像测试。验证草稿A/B隔离、旧提交不清新内容、空草稿不被服务端snapshot覆写、中文输入法防误发。
人工验证连续进入不同卡2-3轮/返回并辨认聊过；原位置/收藏筛选/续聊仍在；同角色多故事摘要；上翻后新回复提示且不强制拉回。
影像验证我的生成→历史→返回、同款→参数/描述→生成、继续编辑时旧提交/再生成不清草稿、查询失败只读重试、保存兜底、320px+键盘。真实生成/Telegram能力另行验收，不用 mock 结论代替。
