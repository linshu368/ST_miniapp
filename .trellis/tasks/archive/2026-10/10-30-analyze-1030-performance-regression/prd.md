# 30 日性能下降部署链路分析

## Goal

解释 2026-10-30 性能日报相对 24–29 日明显下降的原因，将页面/API P95 变化与 GitHub 提交、Railway 实际部署、运行资源和错误日志按时间对齐，形成可复核结论。

## Requirements

- 固定日报统计窗口，避免把自然日、UTC 和北京时间混用。
- 读取 24–30 日已有日报，区分样本量变化、前端导航、接口响应和完整流式生成耗时。
- 核对本地 Git、GitHub 远端提交/合并以及 Railway deployment 实际生效时间和 commit SHA。
- 只读核对 Railway HTTP 响应时间、错误率、CPU/内存/网络、重启和运行日志。
- 结合 Sentry/Grafana 数据判断是版本回归、平台资源、外部供应商、流量结构或统计口径变化。
- 不修改生产配置、不重新部署、不写 Sentry/Railway/GitHub 状态。
