# 小范围调整：自动探测本机 IP

用户明确要求不再配置 PAYMENT_PROBE_CLIENT_IP。复用现有独立探测模块，仅将该字段从配置中移除：使用 Node os.networkInterfaces 选择非回环 IPv4，无匹配时回退 127.0.0.1。该值是容器/进程本地地址，不声称是 NAT 后公网出口；不使用外部 IP 查询服务，不增加网络调用、状态、依赖、数据库对象或用户支付行为变化。

默认开关和渠道、金额、一次请求、超时、策略、告警及取消逻辑保留。正常用户继续通过既有 route 提供 IP。移除配置解析、IaC 和 env example；更新维护指南、README、运维和 spec。原归档任务保留历史，新增本次更正记录。

复用 probe.ts 与既有 probe/script 测试，不新建测试文件。由于协议仍必须携带 clientip，现有回归要确认无需配置即可发送合法本机 IPv4、空网卡/仅回环回退及无上游重试。运行相关及 backend 全量测试、全包 typecheck、IaC 本地校验、复杂度/导入/格式检查。此前 Frontend/Admin build 覆盖的源码本轮未变，无需重复 build。真实 TTZF 对服务器本地 IP 的受理尚未验证，上线时观察明确响应，不能当作公网来源检测。

回退只回退此字段选择逻辑或关闭探测开关；不影响用户订单/结算。不自动部署或真实建单。完成文档同步后归档本次更正。
