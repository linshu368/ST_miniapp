# Workspace Index

Records of AI agent work across developers.

Initialize a local developer identity before recording sessions:

```bash
python ./.trellis/scripts/init_developer.py <your-name>
```

This creates `.trellis/.developer` and `.trellis/workspace/<your-name>/`. Local runtime pointers are ignored by `.trellis/.gitignore`.

Session records should include:

- date
- task
- branch
- main changes
- verification
- next steps
