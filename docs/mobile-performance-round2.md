角色编辑器就绪口径更严格：工程指标`source_measurement_version=creator_draft_ready_v2`，仍由`navigation_type`区分文档/SPA/挂载。新旧定义应分别比较，不能将口径变化解释成提速。新增creator/creator_public/character_wishes分类也无法回填历史other数据。

视频交付每轮最多4个5MiB分块，连续上传批次达到20秒后不再起新块；原2并发和源大小限制不变。源下载/非幂等创建/在途分块保持原15/60/120秒有界超时，20秒不能人为截断非幂等POST，也不保证整轮包含下载只花20秒。编码只读验证沿20秒期限，所有外部调用继续响应停止信号。HEAD校验真实偏移，源字节不跨轮缓存。只有已结束的网络操作和已知TUS会话允许安全释放；creating或publish结果未知继续保留保护，强杀仍按原五分钟租约恢复。停止最多等待30秒，超时记录unknown，不宣称任务完成。没有新增迁移、数据库列、HTTP契约、配置key或依赖。

Sentry CR身份故障的脱敏样本没有足够cause信息，F4只有一次未映射React堆栈，当前不宣称这两组问题已修复。既有身份超时/缓存及聊天回归继续验证，不以吞错或猜测性状态改写处理未知故障。

发布后验证需Android/iOS分别记录P95与N、失败/stall/left和新Sentry事件。冷启动目标4秒，聊天/角色页面目标2秒；样本不足不能填零。本地测试通过仅说明代码行为通过固定场景，不代表线上目标达成。详细冷启动证据见 `.trellis/tasks/11-19-cold-start-round2/research/diagnosis.md`；本地检查结果汇总在父任务`verification.md`。
