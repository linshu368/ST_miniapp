| 点              | settle（即时）                                                             | sync-job（30s 回捞）                                                |
| --------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `reply_outcome` | 有正文且 `status=success` 且 `finishReason` 为 `stop` 或 `null` → complete | 有正文且 `record.status=success` → complete，**不看 finish_reason** |

| 金额来源        | `getInitialBillingDecision`                                                | 原 charge 行的 `fixed_deduction`                                    |
